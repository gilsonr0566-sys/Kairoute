## New tests added (tools/full-test.sh runs all of them)
- `tools/full-test.sh`: one command runs every check. It re-runs each failure once alone, writes `test-results/full/summary.json`, and writes `DONE` when finished. `ONLY="a b"` runs a few checks into `test-results/only`.
- `tools/static-check.cjs`: looks for keys or passwords written into the repo, eval, functions defined twice, plain-http addresses and scripts from unexpected hosts. Passed: 174 files, 685 functions.
- `tools/worker-check.mjs`: the helper, run offline. Another website gets "Not allowed" and never reaches the AI. Broken requests get a 400. When the allowance is used up, the AI is not called. Huge prompts are cut. Passed 103 checks.
- `tools/inject-check.cjs`: HTML and script payloads go into sight names, descriptions and day titles, on every page of every day, phone and tablet. None ran. Payloads appeared as plain text on 176 of 264 pages.
- `tools/stress-check.cjs`: 400 fast taps per device, every sight ticked on every city day, and a reload keeps the trip.
- `tools/a11y-check.cjs`: names for buttons and fields, alt text, page language, zoom allowed (passed). `CONTRAST=1` adds the readability check, which is suggestion-only.
